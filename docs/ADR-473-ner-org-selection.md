# ADR-473 — Выбор полного названия организации по предложениям двух моделей

Статус — владелец утвердил конфигурацию для внедрения в эпике #428
23 ноября 2026 года. Реализация проходит через #431 и #432. Публичный
контракт LOC подлежит отдельному утверждению в #431.

## Конфигурация

Контроль #471 — Gather INT8 и перепроверка #445 с правилом закрывающей
кавычки. В #473 после вызова #445 в предложении, направленном только русской
модели, отбираются пары ORG, в которых один интервал строго вложен в другой.
Для внешнего интервала Gather используются спорные предложения Gather,
отклонённые при обычной перепроверке. Для внешнего интервала #445 берутся
новые предложения #445 и вложенные спорные предложения Gather. Совокупное
покрытие непробельных символов внешнего интервала должно составлять минимум
25%. Достаточен уже принятый адаптером положительный логит Gather.
Решение исключает перекрытие с сохранённым предложением другого типа.
Далее применяется штатное разрешение пересечений с приоритетом словаря.
Правила используют результаты уже выполненных вызовов обеих моделей.

## Результаты оценки

На раскрытых v2, v3, #469 и #471 пороги 80% precision и 75% recall
выполнены во всех группах. На раскрытом #471 RU ORG выросла с 15/28 до
21/28 при сокращении FP с двух до одного. В остальных группах
наблюдалась одна новая верная EN ORG. Ни одна из 48 конфигураций не прошла
критерии обеих выборок для подбора. Зафиксированный диагностический
вариант показал 68,4% precision и 46,4% recall по RU ORG на отдельной
синтетической валидации.

Новый слепой тест включает 80 независимо подготовленных синтетических
документов, по 40 на язык. Корпус сверили на пересечения с предыдущими
корпусами и наборами подбора. Конфигурацию зафиксировали до раскрытия.
Точные границы и тип сравнивались по #429. В таблице указаны TP / FP / FN
и precision / recall. Пороги проверены по неокруглённым значениям.

| Группа | Контроль #471 | Вариант #473 |
| --- | --- | --- |
| RU PERSON | 27 / 1 / 2 · 96,4% / 93,1% | 27 / 1 / 2 · 96,4% / 93,1% |
| RU ORG | 23 / 1 / 6 · 95,8% / 79,3% | 25 / 1 / 4 · 96,2% / 86,2% |
| RU LOC | 26 / 1 / 1 · 96,3% / 96,3% | 26 / 1 / 1 · 96,3% / 96,3% |
| EN PERSON | 27 / 0 / 1 · 100% / 96,4% | 27 / 0 / 1 · 100% / 96,4% |
| EN ORG | 27 / 1 / 0 · 96,4% / 100% | 27 / 1 / 0 · 96,4% / 100% |
| EN LOC | 25 / 0 / 2 · 100% / 92,6% | 25 / 0 / 2 · 100% / 92,6% |

Обе конфигурации прошли обе границы в шести группах. Единственное
изменение после объединения — две дополнительные точные RU ORG, обе
с полным интервалом от #445. Из пяти рассмотренных пар этого направления
отбор принял три, одну исключило объединение. Исходные находки сохранены.
В каждом варианте зафиксировано 30 вызовов перепроверки. Повтор дал
побайтово идентичные агрегированные результаты.

## Ресурсы

Замеры по #429 выполнены до слепого теста на одном логическом ядре
Ryzen 5 5600. Каждый из трёх свежих процессов обработал 1800 документов
после прогрева и уложился в утверждённый бюджет #428. Перепроверка
