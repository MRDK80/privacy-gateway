Separately authorized typed final effects may use the existing final Ledger writer after the full installed original five-file graph, candidate/report/current-source/CI/mandate join. No reset, refund, local ref rewrite, new lifetime, or extra effect is introduced.

These are repeated original-source checks, not atomic GitHub snapshots, crash transactions, cryptographic proof of human authorship or a guarantee that historical CI remains available.
