# ADR-200 amendment — #208: текст приватных findings

Статус: принято для реализации #208. Родительские решения: ADR-200 и amendment #204.

Для `requirement`, `evidence` и `required_fix` используется отдельный алфавит,
включающий `/`; алфавит сводок gate не меняется. До фильтрации отклоняется всё
поле с абсолютным, домашним, временным, Windows/UNC-путём или `..` как
компонентом пути. Секретоподобные фрагменты также отклоняют всё поле.
Сорокасимвольный hex после `snapshot commit` или `commit` распознаётся как
идентификатор Git snapshot, а остальные длинные смешанные строки по-прежнему
проходят проверку на секретоподобность.
Ограничение длины остаётся 200/100/200 символов. Усечение выполняется по
границе слова, если она есть; `redaction.truncated_fields` перечисляет
усечённые поля. Если первое слово превышает лимит, поле отбрасывается.

`redaction.version` становится `"3"`; читатель принимает старые формы
`"1"`/`"2"` без нового ключа и форму `"3"` с ключом. Версия приватной записи
остаётся `1.2`: изменяется вложенная версия редакции, а не структура записи.
`finding_fingerprint` вычисляется из исходного finding до редакции и не
меняется от алфавита и лимита. Одинаковые исходные объекты сравнимы между
версиями редакции; текстовые выжимки между версиями сравнивать нельзя.
Публичная запись, stdout и коды ошибок не меняются.
