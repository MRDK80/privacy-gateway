# Синтетические примеры agent contracts

- `task.json` — закреплённый вход задачи;
- `executor-pass.json` — компактный отчёт успешного executor;
- `controller-pass.json` — независимый verdict без blocking findings;
- `controller-fail.json` — исправимый blocking finding с безопасным evidence.

Все значения синтетические. Форматы и trust/visibility rules описаны в
[`docs/agent-contracts.md`](../../docs/agent-contracts.md).
