# Privacy Gateway

Локальный Python-инструмент для безопасной подготовки корпоративных текстов перед ручной передачей во внешнюю языковую модель.

> **Статус:** ранний MVP — Этап Э2. Команда `pgw detect` доступна для диагностики. Команды `prepare` и `restore` пока не реализованы.

## Принцип работы

Вся обработка выполняется **локально**. Privacy Gateway обнаруживает потенциально чувствительные сущности в тексте и выводит структурированные метаданные. Псевдонимизация, токенизация и шифрованная карта кейса будут реализованы в следующих этапах.

На Этапе Э2 доступна только техническая команда `pgw detect`. Она **диагностическая** и не гарантирует полноту обнаружения. Команда не является разрешением передавать исходный текст внешней модели.

## Требования

- **Windows** 10/11 или **Linux** (Ubuntu 22.04+, Linux Mint 21+, Debian 12+)
- Python 3.11+

## Установка

### Linux / Linux Mint (bash)

```bash
sudo apt update
sudo apt install python3.11 python3.11-venv

python3.11 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

Если `python3.11` отсутствует в репозиториях Linux Mint, используйте deadsnakes PPA или системный `python3` версии 3.11+:

```bash
python3 --version   # должно быть 3.11 или выше
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

### Windows (PowerShell)

```powershell
py -3.11 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

Если политика выполнения PowerShell блокирует активацию:

```powershell
.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

## Использование

```bash
pgw --help
pgw detect --help

# Анализ файла
pgw detect input.txt

# Явная кодировка
pgw detect input.txt --encoding utf-8
pgw detect input.txt --encoding cp1251

# Из stdin
pgw detect -
```

Вывод — JSON-метаданные обнаруженных сущностей. Исходный текст и значения сущностей в вывод **не включаются**.

Детектор распознаёт пути всех трёх форматов (UNC, `C:\...`, `/opt/...`) независимо от текущей ОС, поскольку анализируется содержимое текста, а не файловая система.

## ⚠️ Политика безопасности

**Не добавляйте в этот репозиторий реальные корпоративные данные.**
Это касается имён, организаций, адресов электронной почты, имён серверов, IP-адресов, ссылок на документы, финансовых показателей и любой другой идентифицирующей информации.

Полная политика — в файле [SECURITY.md](SECURITY.md).

Privacy Gateway **не гарантирует** юридической, абсолютной или полной защиты данных. Это инструмент на стадии разработки; он должен применяться в рамках комплексной практики информационной безопасности.
